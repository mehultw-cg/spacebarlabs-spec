## ADDED Requirements
### Requirement: Core Navigation and Theming
The application SHALL provide persistent navigation, a footer, and a consistent space-themed glassmorphic visual style with dark mode support.

#### Scenario: Dark Mode Toggle
- **WHEN** user clicks the theme toggle
- **THEN** the application switches between light and dark modes seamlessly

#### Scenario: Navbar Navigation
- **WHEN** user clicks a link in the navbar
- **THEN** the view scrolls to the corresponding section or navigates to the page

#### Scenario: Space Theme Visuals
- **WHEN** the application loads
- **THEN** the background and elements exhibit space-themed colors and glassmorphic effects
