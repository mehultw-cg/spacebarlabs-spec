## Why
The landing page lacks essential navigation, footer, and a cohesive theme. We need to implement these core elements to provide a complete user experience and establish the "SpaceBar Labs" brand identity (space theme, glassmorphism).

## What Changes
- **Navbar**: Implement a responsive, resizable navbar using Aceternity UI components.
- **Footer**: Create a standard footer with links and contact info.
- **Dark Mode**: Enable dark mode using `next-themes` and Shadcn UI best practices.
- **Global Theming**: Apply space-themed aesthetics, glassmorphism, and SVG backgrounds.

## Impact
- **Affected Specs**: `ui` (new capability)
- **Affected Code**: `src/components/layout`, `src/app/layout.tsx`, `src/app/globals.css`
