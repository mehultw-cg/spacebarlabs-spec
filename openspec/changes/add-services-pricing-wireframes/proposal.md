# Add Services & Pricing Wireframes Proposal

## Why
To quickly establish the basic layout and structure for the Services and Pricing sections of the Aurorys Labs landing page. This initial wireframe will serve as a foundation for content and styling, allowing for early feedback and iterative development before applying the global glassmorphic theme.

## What Changes
- Add a Services section to the homepage (`src/app/page.tsx`) using shadcn/ui components (e.g., `Card`,`Text`, etc.).
- Add a Pricing section to the homepage (`src/app/page.tsx`) using shadcn/ui components (e.g., `Card`, `Button`, `Text`, etc.).
- Implement these sections with placeholder content and minimal default styling to focus on layout.
- Ensure the new sections are responsive.

## Impact
- Affected code: `src/app/page.tsx`
    - Creation of new components and adding them to main page layout.
- Affected specs: Potentially a new `landing-page-init-scaffolding` capability or extending `initial-project-setup` if it covers application UI.
